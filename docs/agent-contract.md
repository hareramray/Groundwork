# Browser CLI implementation contract

Standalone local CLI entry `python -m grounding.agent_cli`, Windows wrapper `scripts/agent.ps1`. It accepts the generated training checkpoints and inference exports directly by filesystem path, without requiring SQLite/server. No pretrained planner, OCR, or DOM-selector grounding. Target locations come from model screenshot predictions. Commands/task files supply intent and sequence; this grounder is not a general language planner.

## Model adapter (agent ownership)

`grounding.agent_model.FileGrounder(path, device='auto', threshold=0.5, trust_checkpoint=False)` loads once. `.predict(png_bytes, instruction, threshold=None)->dict` same prediction shape as `inference.predict` including original screenshot dimensions, normalized bbox/click, presence_score, unknown_words. `.metadata` dict architecture/classes/config/checkpoint/kind. Safe `weights_only=True` default for inference exports; generated full training checkpoints contain numpy RNG pickle data and may need narrowly allowlisted numpy types OR explicit trusted local checkpoint flag. Clear error on arbitrary state_dict, unknown architecture/preprocessing, missing tokenizer/classes, and malformed tensors. Never modify source checkpoint. CUDA CPU fallback controlled device override. Tests own tests/test_agent_model.py.

## Browser transport (agent ownership)

`grounding.browser_runtime.BrowserHub(port=8766)` starts authenticated loopback-only extension relay on enter; `.close()` stops bridge/detaches only and does not close user's tabs/browser. `.token` string, `.bridge_url` http URL, `.list_browsers(endpoints=None)->list[dict]` discovers connected extensions and CDP-enabled running Chrome/Edge (common localhost ports and process command flags; no broad network scan). `browser dict {id,name,transport:'extension'|'cdp',endpoint?,...}`. `.connect(browser_id)->BrowserConnection`.

`BrowserConnection` `.list_tabs()->list[{id,title,url,active?,window_id?}]`; `.select_tab(id)` explicitly chooses page; `.capture()->dict{png:bytes,width,height,viewport_width,viewport_height,url,title,tab_id}` visible viewport PNG only. `.click(x,y)`, `.type_text(text,replace=True)`, `.press(key)`, `.scroll(dx,dy)`, `.navigate(url)`, `.describe()->dict{tab_id,url,title,viewport_width,viewport_height}` and `.close()`. Coordinates CSS viewport pixels; screenshot image dimensions may differ devicePixelRatio. Key canonical Playwright names (`Enter`, `Control+A`, `Tab`, etc.). No CSS/DOM target lookup. Browser attach must not close unrelated pages. `.launch(browser='edge'|'chrome'|'chromium',url='about:blank',headless=False)->browser dict` launches a separate local profile managed through CDP; interactive launch only on user CLI command, not at module import. Tests can launch headless Chromium. Use Python Playwright adapter and Chrome MV3 extension under browser-extension/ for normal existing tabs. Extension connects via user-supplied token and loopback relay, lists open browser tabs, capture via chrome.debugger Page.captureScreenshot, input via debugger Input commands, tab navigation via tabs.update. Reconnection/token errors actionable. CDP local endpoints only. browser/runtime tests own tests/test_browser_runtime.py, tests/test_extension_bridge.py if needed. Agent may adjust contract by message.

## CLI and engine (root ownership)

`grounding.agent_engine` defines validated action/task schema, parser for explicit commands, sequential observe-ground-act-observe, bounded scroll search, presence abstention, CSS coordinate mapping, stale viewport guards, step budget, action confirmations by default / explicit --auto for user task sequence, JSONL local logs + before/after screenshots. Capture separately for each action, never reuse a box across scroll/navigation. Page content never interpreted as instructions. No arbitrary JS/shell task actions. Raw type text omitted from default logs. CLI commands: browsers, connect, tabs, use, model, screenshot, find <instruction>, click <instruction>, type "text" into <instruction>, press <key>, scroll up|down [pixels], open <http(s) URL>, wait <seconds>, run <task.json>, help, quit. Task JSON `{name,steps:[{action:'click'|'type'|'find'|'press'|'scroll'|'navigate'|'wait'|'assert_visible',instruction?,text?,key?,dx?,dy?,url?,seconds?,search_scrolls?}]}`. Scripted mode `--task`, `--browser-id` or `--endpoint`, `--tab`, `--model`, `--device`, `--threshold`, `--auto`; discovery/model-selection menus if omitted on terminal. Root tests tests/test_agent_engine.py.

## Documentation/verification (agent ownership)

docs/browser-agent.md, scripts/agent.ps1, examples/browser-task.json, local demo HTML + task script, optional smoke script `scripts/agent_smoke.py`. Browser smoke uses disposable local HTML served at loopback and headless browser with real `.pt` inference, never user's real browser; deterministic test fixtures may create constant-output model weights clearly identified as integration fixtures, not learned performance. Verify transport, coordinate scale, real saved PT selection/click/type, abstention prevents click, disconnect leaves browser/tab intact. No claims of unrestricted web automation or arbitrary-goal planning. End user normal Chrome/Edge extension install is manual developer-mode Load unpacked and connect token. Core setup adds required Python Playwright pins by root; docs update usage instructions.
